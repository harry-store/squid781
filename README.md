# 🦑 ระบบสต๊อกปลาหมึก (Squid Inventory Management System)

เว็บแอปพลิเคชันจัดการสต๊อกปลาหมึก ออกแบบมาเพื่อความรวดเร็ว โหลดไว ใช้งานง่ายบนมือถือและคอมพิวเตอร์ รองรับการนำขึ้น **GitHub Pages** และเชื่อมต่อกับ **Google Sheets** ผ่าน **Google Apps Script**

---

## 🌟 จุดเด่นและฟังก์ชันการทำงาน

### 1. 📥 เมนูรับเข้า (Stock In)
- **บล็อคสรุปด้านบน**: แสดงน้ำหนักรวม (กก.), ยอดค่าใช้จ่ายรวม (บาท), และจำนวนบิล
- **ช่องค้นหา**: พิมพ์บางคำเพื่อค้นหาชื่อซัพพลายเออร์ได้ทันที
- **ตัวกรองเวลา**: วันนี้, อาทิตย์นี้ (นับวันจันทร์-อาทิตย์), เดือนนี้, ปีนี้ และทั้งหมด
- **ปุ่มบันทึกรับเข้า**:
  - เลือกหรือพิมพ์ค้นหาชื่อซัพพลายเออร์ (มีระบบ Autocomplete แนะนำชื่อเดิม)
  - รายการสินค้า: **หมึกหอม**, **หมึกกระดอง**, **หมึกกล้วย**
  - กรอกจำนวนกิโลกรัม และ ราคาต่อกิโลกรัม (คำนวณยอดเงินรวมให้อัตโนมัติ)
  - บันทึกลง Google Sheet พร้อมวันเวลา Timestamp
- **กดดูประวัติซัพพลายเออร์**: เมื่อคลิกที่รายการใด จะเปิดหน้าต่างสรุปประวัติการส่งของซัพพลายเออร์รายนั้น ยอดสะสม และรายการบิลทั้งหมด

### 2. 📤 เมนูขายออก (Stock Out)
- **บล็อคสรุปด้านบน**: แสดงน้ำหนักขายรวม, ยอดขายรวม, และยอดรอชำระ
- **ช่องค้นหา**: ค้นหาตามชื่อลูกค้า
- **ตัวกรองเวลา**: วันนี้, อาทิตย์นี้ (นับวันจันทร์-อาทิตย์), เดือนนี้, ปีนี้ และทั้งหมด
- **ปุ่มบันทึกขายออก**:
  - พิมพ์ค้นหาชื่อลูกค้า โดยระบบจะดึงเบอร์โทรศัพท์และที่อยู่เดิมมาแสดงอัตโนมัติ
  - เลือกสินค้า (**หมึกหอม**, **หมึกกระดอง**, **หมึกกล้วย**) พร้อมดึงราคาขายมาตรฐานมาให้อัตโนมัติ (แก้ไขได้)
  - สถานะการชำระเงินเริ่มต้นถูกตั้งเป็น **"รอชำระ"** อัตโนมัติ
- **กดดูประวัติ & ปรับสถานะ**: คลิกที่รายการเพื่อดูรายละเอียด และกดปุ่มเปลี่ยนสถานะจาก **"รอชำระ"** เป็น **"ชำระเงินแล้ว"** ได้ทันที

### 3. 📊 เมนูแดชบอร์ด (Dashboard)
- **สต๊อกคงเหลือปัจจุบัน**: คำนวณจาก (รับเข้าทั้งหมด - ขายออกทั้งหมด) แบบเรียลไทม์ แยกเป็นรายสินค้า:
  - 🦑 หมึกหอม (กก.)
  - 🐙 หมึกกระดอง (กก.)
  - 🦑 หมึกกล้วย (กก.)
- **สรุปการเงินประจำเดือน**: นับตั้งแต่วันที่ 1 ของเดือนปัจจุบัน
  - 💸 ค่าใช้จ่ายรับเข้าเดือนนี้
  - 📈 ยอดขายที่ชำระแล้วเดือนนี้
  - 💰 กำไรเดือนนี้ (คำนวณจาก: ยอดขายที่ชำระเงินแล้ว - ค่าใช้จ่ายรับเข้าเดือนนี้)
- **รายการลูกค้าที่ยังไม่ชำระ**: แสดงรายการบิลที่ค้างชำระ พร้อมปุ่มกดรับชำระได้ทันทีจากหน้าแดชบอร์ด

### 4. 📱 เมนูล่างสุด (Bottom Navigation)
- แถบเมนูติดอยู่ด้านล่างหน้าจอถาวร (Fixed Bottom Bar) ใช้งานสะดวกด้วยมือเดียวบนสมาร์ตโฟน

## 🚀 วิธีติดตั้งและใช้งาน

### ขั้นตอนที่ 1: ตั้งค่า Google Sheet และสร้างหัวตารางอัตโนมัติ
1. ไปที่ [Google Sheets](https://sheets.new) แล้วสร้างชีตใหม่ (ตั้งชื่อเช่น `ระบบสต๊อกหมึก`)
2. ที่เมนูด้านบน เลือก **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมในโปรเจกต์ทิ้ง แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ [`Code.gs`](file:///d:/พี่วรรณ/squid/Code.gs) ไปวาง
4. กดบันทึก (ไอคอนรูปแผ่นดิสก์ 💾)
5. **สร้างแผ่นงานและหัวตารางทันที**:
   - ที่แถบด้านบนของ Apps Script เลือกฟังก์ชัน **`setupSheets`** แล้วกดปุ่ม **เรียกใช้ (Run)**
   - โค้ดจะสร้างแผ่นงาน 5 ชีตพร้อมใส่สีแท็บ หัวตารางสีสวยงาม ตรึงแถวบน และปรับความกว้างคอลัมน์ให้อัตโนมัติทันที!
   - *(หรือเมื่อเปิดหน้าชีตขึ้นมาใหม่ จะมีเมนู **"🦑 จัดการระบบสต๊อกหมึก"** ปรากฏอยู่บนแถบเมนู สามารถกดสร้างหรือใส่ข้อมูลตัวอย่างทดสอบได้เลย)*
6. กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
   - เลือกประเภท (Select type): **เว็บแอป (Web app)**
   - คำอธิบาย (Description): `v1`
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ GitHub Pages เรียกใช้งานได้)*
7. กด **ทำให้ใช้งานได้ (Deploy)** และให้สิทธิ์การเข้าถึง (Authorize access)
8. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

### ขั้นตอนที่ 2: เชื่อมต่อ Web App URL กับหน้าเว็บ
1. เปิดหน้าเว็บ `index.html` บนเบราว์เซอร์
2. กดไอคอนรูปเฟือง ⚙️ ที่มุมขวาบน
3. นำ Web App URL ที่ได้จากขั้นตอนที่ 1 มาวางในช่อง **Apps Script Web App URL** แล้วกด **บันทึกการตั้งค่า**
4. ระบบจะทำการซิงค์ข้อมูลกับ Google Sheets ของคุณทันที!

### ขั้นตอนที่ 3: นำขึ้น GitHub Pages
1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `style.css`, `app.js`, `Code.gs`) ขึ้น GitHub Repository ของคุณ
2. ใน GitHub Repository ไปที่ **Settings** > **Pages**
3. ในหัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** หรือ **master** และโฟลเดอร์ **/ (root)**
4. กด **Save** รอประมาณ 1-2 นาที GitHub จะสร้างลิงก์เว็บไซต์ให้คุณ เช่น `https://username.github.io/squid/`
5. เปิดลิงก์บนมือถือและสามารถเพิ่มลงหน้าจอโฮม (Add to Home Screen) เพื่อใช้งานเหมือนแอปพลิเคชันได้เลย!

## ⚡ ทำไมถึงโหลดเร็ว?
- เขียนด้วย Pure Vanilla JavaScript + Modern CSS น้ำหนักเบามาก (ขนาดไฟล์รวมไม่ถึง 40KB)
- ไม่มี Framework หนักๆ ทำให้เปิดปุ๊บติดปั๊บทันทีแม้เน็ตมือถือช้า
- มีระบบ Local Cache เก็บข้อมูลในเครื่อง ทำให้กดสลับเมนู กรองวันที่ และค้นหาได้แบบ Instant (0 วินาที)
- ซิงค์บันทึกข้อมูลกับ Google Sheets ในเบื้องหลัง (Background sync) ไม่ทำให้หน้าเว็บกระตุก
